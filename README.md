# FourSeasons - 四时絮语

为 Typecho 博客添加四季粒子特效，支持春/夏/秋/冬四种场景独立开关控制，每个季节可独立调节数量、速度、大小，并支持简约模式切换。

## 效果预览

- **春季**：单瓣樱花飘落，3D 翻转旋转，带柔光
- **夏季**：淡黄绿微光缓缓向上飘移，柔和不刺眼
- **秋季**：五瓣枫叶飘旋下落，边缘清晰带叶脉
- **冬季**：真实六角冰晶雪花，近大远小三层视差

## 安装方法

1. 创建文件夹 `FourSeasons`，在里面创建 `assets` 子文件夹
2. 将 `Plugin.php` 放到 `FourSeasons/` 目录
3. 将 `seasons.js` 放到 `FourSeasons/assets/` 目录
4. 将整个 `FourSeasons` 文件夹上传到 Typecho 的 `/usr/plugins/` 目录
5. 登录后台，进入"控制台" → "插件管理"找到 "FourSeasons" 点击启用
6. 点击"设置"选择要开启的季节效果

## 配置说明

| 季节 | 开关 | 数量 | 速度 | 大小 | 说明 |
|------|------|------|------|------|------|
| 简约模式 | 关闭/开启 | — | — | — | 用简化形状代替复杂形状 |
| 春季 | 关闭 | 50 | 0.8 | 0.9 | 樱花飘落，3D 翻转 |
| 夏季 | 关闭 | 35 | 1.0 | 1.0 | 淡黄绿微光向上飘 |
| 秋季 | 关闭 | 30 | 0.8 | 0.8 | 枫叶飘旋下落 |
| 冬季 | 开启 | 50 | 0.6 | 0.6 | 六角冰晶雪花，三层视差 |

### 参数范围

- **数量**：春 10~150 / 夏 10~100 / 秋 5~50 / 冬 10~200
- **速度**：0.3~3.0（1.0 为默认速度）
- **大小**：0.5~2.5（1.0 为默认大小）

## 季节特效细节

### 春季 - 樱花
- 单瓣粉色樱花从顶部飘落
- 3D 翻转效果（rotateX/Y 模拟透视变化）
- 透光感（opacity 0.5~0.78）+ 柔光阴影
- 简约模式：简化花瓣形状（椭圆+小尖）

### 夏季 - 柔和微光
- 淡黄绿色光点（rgb 200~220, 220~235, 155~180）
- 极低透明度（0.2~0.38），柔和不刺眼
- 缓缓向上飘移 + sin 左右轻微摆动
- 飘出顶部后从底部循环进入
- 简约模式：淡黄绿圆点

### 秋季 - 枫叶
- 五瓣枫叶轮廓（10 段 bezier 曲线）
- 边缘清晰 + 叶脉纹理
- 飘旋下落（sin 摆动 + 缓慢旋转）
- 4 种秋色随机（橙红/金黄/深红/暖棕）
- 简约模式：简化枫叶轮廓（五瓣+叶柄）

### 冬季 - 雪花
- 真实六角冰晶 dendrite 结构
- 三层视差：前景大清晰快 / 中景中等 / 背景小模糊慢
- 6 个主臂 + 3 层 V 形分叉 + 冰纹装饰
- AliceBlue 半透明冰晶色
- 简约模式：圆点粒子，保留三层视差差异

## 交互特性

- **鼠标风向**：鼠标移动时粒子受风力偏移
- **刷新无缝**：通过 sessionStorage 保存/恢复粒子位置，刷新后从上次位置继续飘
- **切标签暂停**：切换浏览器标签页时自动暂停动画，节省资源
- **防抖 resize**：窗口大小变化时防抖处理，粒子按比例缩放

## 技术细节

- 基于 HTML5 Canvas 2D 渲染
- `requestAnimationFrame` 流畅动画
- `sessionStorage` 状态保持
- 响应式防抖 resize
- 零依赖，无需外部库
- 兼容 Typecho 1.2+
